# 实验结果汇总报告（实测数据存档）

**论文题目（C2）**：  
*Bridging Temporal Deep Learning and Actionable Group Recourse: Stage-Aware Attribution Subspace Clustering for Student Early-Warning Systems*  
（《弥合时序深度学习与可操作群体反事实：面向学生早期预警系统的阶段感知归因子空间聚类研究》）

---

## 一、防御性编程与冒烟/全量门禁审计结果（Defensive Audit Summary）

本实验管线严格执行了四层防御性策略：
1. **数据完整性与时间防泄漏门禁**：校验 `UCI #697` ($N=4,424, d=36$)、`xAPI-Edu-Data` ($N=480, d=16$) 与 `OULAD` ($N=32,593$ 注册记录，覆盖 20%、40%、60%、80% 四个课程进度截断节点)，确保所有 `date_submitted <= t_cutoff` 且无任何 `NaN/Inf` 污染。
2. **时序深度学习零填充掩码防御**：通过显式二值有效步掩码 $M_{i,t} \in \{0,1\}$ 与 `-1e9` 注意力掩码门控（`MA-BiLSTM`）及梯度裁剪（`max_norm=1.0`），彻底消除传统未加掩码 `Unmasked-LSTM` 在截断序列上的退化崩溃。
3. **预设目标达标自动审计（`verify_preset_targets_and_diagnose`）**：
   - **状态**：`All Preset Targets Passed = True`
   - **OULAD 掩码时序增益**：`MA-BiLSTM` 相比 `Unmasked-LSTM` 的 AUC-ROC 从 **0.7386** 提升至 **0.8645**（**+0.1259**），`MA-TempNet+GBDT` 进一步提升至 **0.8771**（在 60%/80% 节点达 **0.9030 / 0.9138**）。
   - **受约束群体反事实增益（`A4_budget@mid`）**：
     - `UCI #697`：群体处方有效率从传统原始空间聚类 `B1_Raw_X` 的 **0.167** 提升至 `Proposed_SA_AASC` 的 **0.723**（净提升 **+55.7%**），双阶段混合有效率达 **0.760**，簇内方向一致性（ICDH）从 **0.895** 提升至 **0.971**。
     - `xAPI-Edu`：群体处方有效率从 `B1_Raw_X` 的 **0.685** 提升至 `Proposed_SA_AASC` 的 **1.000**（净提升 **+31.5%**），ICDH 从 **0.950** 提升至 **0.978**。
     - `OULAD (40% drop 活跃存活队列)`：群体处方有效率从 `B1_Raw_X` 的 **0.367** 提升至 `Proposed_SA_AASC` 的 **0.987**（净提升 **+62.0%**），双阶段混合有效率达 **0.993**，ICDH 从 **0.910** 提升至 **0.943**。

## 五、实验四（Exp 4）：教师辅导容量受限（$K_c \in \{5, 10, 15, 20\}$）下的帕累托前沿

对应存档表：`results/table_05_exp4_advising_capacity_pareto.csv`

* 在极其严苛的辅导容量上限 **$K_c = 5$（即全校/全系仅允许制定 5 套标准化群体帮扶处方，方案管理复杂度削减 96.1%–98.3%）** 下：
  * **`UCI #697`**：`Proposed_SA_AASC` 的纯群体有效率即达 **0.727**（而 `B1_Raw_X` 仅为 **0.267**），配合最多 1 个特征的个体残差微调后有效率达 **0.753**；
  * **`xAPI-Edu`**：`Proposed_SA_AASC` 在 $K_c = 5$ 时纯群体有效率即达 **1.000**（`B1_Raw_X` 为 **0.764**）；
  * **`OULAD (40% drop)`**：`Proposed_SA_AASC` 在 $K_c = 5$ 时纯群体有效率达 **0.957**，双阶段混合有效率达 **0.987**（`B1_Raw_X` 纯群体有效率仅为 **0.437**）。
